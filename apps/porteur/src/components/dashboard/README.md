# Composants Dashboard (`/apps/porteur/src/components/dashboard`)

Ce dossier contient les éléments visuels composant la vue d'ensemble du porteur de projet.

## Fichiers

- **`dashboard-header.tsx`** : Affiche les informations de bienvenue et l'avatar utilisateur.
- **`dashboard-stats.tsx`** : Cartes statistiques résumant les montants levés, projets actifs et investisseurs.
- **`dashboard-projects.tsx`** : Liste des projets récents avec avancement et lien de création.

## Principes de conception

- Composants fonctionnels purs et sans état global direct.
- Taille stricte sous 100 lignes par fichier.
