# Composants Projets (`/apps/porteur/src/components/projets`)

Ce dossier regroupe les éléments de présentation et d'interaction pour la liste des projets du porteur.

## Fichiers

- **`projets-header.tsx`** : Titre et bouton d'action pour la création d'un nouveau projet.
- **`projets-list.tsx`** : Affichage des projets sous forme de lignes interactives avec état vide illustré.

## Bonnes pratiques

- Séparation présentation / logique applicative.
- Fichiers concis (< 80 lignes).
