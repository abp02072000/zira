# Composants Profil (`/apps/porteur/src/components/profil`)

Ce dossier héberge les modules composant l'espace profil et la vérification d'identité des porteurs.

## Fichiers

- **`profile-cover-header.tsx`** : Bandeau de couverture, avatar photo, nom vérifié et coordonnées.
- **`profile-skills-section.tsx`** : Liste interactive des tags de compétences techniques/managériales.
- **`profile-experience-section.tsx`** : Chronologie des expériences professionnelles et diplômes.
- **`profile-edit-dialog.tsx`** : Fenêtre modale d'édition des informations personnelles de base.

## Conformité

- Respect de la limite stricte de 100 lignes de code.
- Commentaires descriptifs et typage TypeScript strict.
