# Composants Détail Projet (`/apps/porteur/src/components/projet-detail`)

Ce dossier structure les modules d'affichage et d'administration d'un projet spécifique.

## Fichiers

- **`project-detail-header.tsx`** : Bandeau, secteur, badge statut et bouton modifier.
- **`project-metrics-grid.tsx`** : Jauges de progression, objectif financier et nombre d'investisseurs.
- **`project-equity-section.tsx`** : Diagramme circulaire de la Cap Table.
- **`project-investments-section.tsx`** : Historique des participations financières reçues.
- **`project-edit-modal.tsx`** : Formulaire d'édition modale rapide du projet.

## Conformité

- Fichiers strictement sous 100 lignes de code.
- Isolation des responsabilités et réutilisabilité.
