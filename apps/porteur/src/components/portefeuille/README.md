# Composants Portefeuille (`/apps/porteur/src/components/portefeuille`)

Ce dossier organise les modules de gestion financière et de suivi des capitaux pour les fondateurs.

## Fichiers

- **`wallet-header.tsx`** : Barre de titre et boutons d'actions principales.
- **`wallet-balance-card.tsx`** : Total globalisé des fonds collectés.
- **`wallet-breakdown-chart.tsx`** : Répartition graphique par projet en Recharts.
- **`wallet-transactions-list.tsx`** : Historique des souscriptions reçues avec avatars.
- **`wallet-action-dialog.tsx`** : Modalité de sélection des passerelles de paiement (Mobile Money, Crypto, Virement).

## Normes de qualité

- Code typé avec Zod / TypeScript.
- Strictement < 100 lignes par composant.
